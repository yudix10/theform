
# theform
theform - это проект по УП, разработанный студентом колледжа для курсовой.

# ФОРМА — Vue 3 + Vite

## Запуск
Установи Node.js LTS, открой папку проекта в VS Code и выполни:

bash
npm install
npm run dev


Открой локальный адрес, который выведет Vite (обычно http://localhost:5173).

## Production-сборка

bash
npm run build


## Структура
- `src/components/SiteHeader.vue` — верхняя строка и шапка.
- `src/components/SiteFooter.vue` — футер и мобильная нижняя навигация.
- `src/styles/main.css` — стили, адаптивность и CSS-переменные.
- `src/assets/images/forma-logo.svg` — исходный логотип.
- `src/App.vue` — корневой компонент.
